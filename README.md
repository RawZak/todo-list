# Список задач

Веб-приложение на Node.js + Express: задачи по дням, календарь, категории,
отложенные и выполненные. Многопользовательское, с регистрацией и входом.

## Запуск

Требуется Node.js 18+.

    npm ci --omit=dev
    npm start

http://localhost:3000, демо-доступ `demo` / `demo1234`.

## Развёртывание

Полный порядок установки, настройка nginx и HTTPS, эксплуатация, бэкапы и
ограничения — в `HANDOVER.md`.
